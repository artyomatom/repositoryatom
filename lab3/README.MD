## Задача 1
Условие:
Тимофей составляет 5-буквенные коды из букв Т, И, М, О, Ф, Е, Й.
Буква Й может использоваться в коде не более одного раза, при этом она:
не может стоять на первом месте,
не может стоять на последнем месте,
не может стоять рядом с буквой И.
Все остальные буквы могут встречаться произвольное количество раз или не встречаться совсем.
❓ Сколько различных кодов может составить Тимофей?
Решение:
Подключаем itertools — там есть полезные инструменты для перебора вариантов.

```
import itertools

def solve():
    letters = "ТИМОФЕЙ"
    valid_count = 0

    for combo in itertools.product(letters, repeat=5):
        word = ''.join(combo)
        y_count = word.count('Й')

        # Если Й встречается больше 1 раза — пропускаем
        if y_count > 1:
            continue

        # Если Й есть ровно один раз — проверяем дополнительные ограничения
        if y_count == 1:
            idx = word.index('Й')

            # Й не может быть на первом или последнем месте (индексы 0 и 4)
            if idx == 0 or idx == 4:
                continue

            # Й не может стоять рядом с И
            if (idx > 0 and word[idx - 1] == 'И') or (idx < 4 and word[idx + 1] == 'И'):
                continue

        # Если все условия выполнены — увеличиваем счётчик
        valid_count += 1

    return valid_count
```

## Задача 3
Условие:
В диапазоне [174457; 174505] найти все числа, у которых ровно два собственных делителя (то есть делителя, отличных от 1 и самого числа).
Для каждого такого числа вывести его минимальный и максимальный собственный делитель.

```
def solve_3():
    results = []

    for n in range(174457, 174506):  # включительно до 174505
        divs = []

        # Перебираем возможные делители от 2 до n
        for d in range(2, int(n**0.5) + 1):
            if n % d == 0:
                divs.append(d)
                if d != n // d:  # избегаем дублирования для полных квадратов
                    divs.append(n // d)

        # Если нашли ровно два собственных делителя
        if len(divs) == 2:
            min_div = min(divs)
            max_div = max(divs)
            results.append((n, min_div, max_div))

    # Сортируем результаты по значению n (на всякий случай)
    results.sort(key=lambda x: x[0])

    return results
```
